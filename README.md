# 🌐 Internet Usage Visualization using Power BI

A comprehensive **Power BI Dashboard Project** for analyzing **Internet Usage Trends** using three different datasets covering:

- 🇮🇳 Indian State-wise Internet Usage
- 🌍 World Internet Usage Statistics
- 📡 Indian Internet Service Providers (ISP) Data

The project performs **data preprocessing, analysis, and interactive visualization** to derive meaningful insights about internet penetration, usage patterns, and provider statistics.

---

## 📌 Project Overview

This project combines multiple datasets to build an interactive Power BI dashboard for exploring internet-related statistics at both **Indian state level** and **global level**.

The workflow includes:

✔ Data Collection  
✔ Data Cleaning & Preprocessing  
✔ Data Visualization using Power BI  
✔ Analytical Insight Generation

---

## 🛠️ Technologies Used

- **Power BI Desktop**
- **Python (Jupyter Notebook)**

## 📂 Dataset Information

### 1️⃣ Indian States Internet Usage Dataset 🇮🇳

File:

```plaintext
indian_states_internet_usage.csv
```

Contains:

- State Name
- Internet Users
- Internet Penetration
- Usage Statistics
- Regional Trends

### 2️⃣ World Internet Usage Dataset 🌍

File:

```plaintext
internet_usage.csv
```

Contains:

- Country Name
- Internet Usage %
- Population Coverage
- Growth Statistics
- Global Comparison Metrics

### 3️⃣ Indian ISP Subscribers Dataset 📡

File:

```plaintext
indian_isp_subscribers.csv
```

Contains:

- Market Share
- Provider Statistics
- Service Distribution

## 🚀 How To Run The Project

### Step 1 — Clone Repository

```bash
git clone https://github.com/your-username/internet-usage-visualization.git
```

---

### Step 2 — Open Power BI Dashboard

Open:

```plaintext
data visualization using power bi.pbix
```

using **Microsoft Power BI Desktop**.

---

### Step 3 — Dataset Connection

If Power BI asks for dataset locations:

Reconnect the CSV files:

- indian_isp_subscribers.csv
- indian_states_internet_usage.csv
- internet_usage.csv

---

### Step 4 — Refresh Dashboard

Inside Power BI:

```plaintext
Home → Refresh
```
